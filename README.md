# Abis Nightclub website

A static, bilingual (English/Tamil) restaurant website built with HTML, CSS and JavaScript. Suitable for GitHub Pages.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive layout and styling
- `app.js` — English/Tamil translations and mobile navigation

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the illustrative food photographs.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `abis-nightclub-website`.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Before publishing
- The address and phone number are based on the Google Maps listing details supplied by the owner.
- Opening hours and menu prices are intentionally not invented.
- The food and interior photos are illustrative stock images. Replace them with your own restaurant photos for a more accurate website.
- The call link uses +91 96007 47282. Confirm the number before launch.
- No online reservation form is included; the site does not claim to submit bookings.
